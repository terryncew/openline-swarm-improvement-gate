Receipt Gate was the first primitive:

add one line around an agent action,
get a receipt,
missing proof quarantines,
no chain means no badge.

The next problem is sharper:

what happens when the agent wants to change itself?

A self-improving swarm should not be allowed to mutate shared behavior just because a member says the change is better.

Did it pass an eval it didn’t write?
Did it hold up on held-out tasks?
Did the health monitor stay clean?
Did the gate itself remain protected?
Is quarantine reversible with new evidence?

Self-improving agents need an immune system, not just a fitness score.

A swarm should not be allowed to mutate itself without receipts.


Claim boundary:

v0.1 is still local and keyless.

It proves mutation-bound receipt structure, not independent real-world guardian identity.

That comes next with signed guardians.
